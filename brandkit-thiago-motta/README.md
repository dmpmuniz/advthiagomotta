# Brandkit Thiago Motta | Advogado: pacote para o agente

Leia nesta ordem: `docs/01` → `02` → `03` → (`04`, `05` se usar padrão/fotos).

```
logos/            assinaturas, monogramas, versões 1 cor, lettering (PNG com transparência)
padrao/           módulo TM em contorno para fundo repetido
fotos-referencia/ mockups de papelaria e acabamentos
docs/             regras de cor, tipografia, uso do logo, padrão, acabamentos
```

## Resumo rápido
- Cores: `#160400` marrom · `#CFA35A` dourado · `#FDF8F0` marfim · `#402B24` trama
- Fontes: títulos Times New Roman Regular · textos Montserrat 400 · destaques Montserrat 500
- Logo claro sobre marfim/branco, logo escuro sobre marrom. Mín. 280 px (assinatura) / 40 px (monograma). Margem = altura do A de "ADVOGADO".
- Nunca digitar o nome da marca: usar sempre a arte.
- Dourado só em detalhes (M, divisória, ADVOGADO, filetes), nunca em texto longo.
- Pendência: o PDF não traz SVG. Pedir vetores ao cliente.

## Instruções para o agente (colar no prompt)
> Ajuste a landing seguindo os arquivos em `docs/`. Substitua qualquer logo/placeholder pelos arquivos de `logos/` conforme o fundo de cada seção. Aplique as variáveis de cor e fontes do `01` e `02`. Respeite margens e tamanhos mínimos do `03`. Use o padrão do `04` apenas em áreas sem texto. Não altere proporções, cores nem digite o nome da marca com fonte.
